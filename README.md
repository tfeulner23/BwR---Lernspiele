# BwR-Lernspiele

Digitale Übungen für den BwR-Unterricht an der bayerischen Realschule.

- [Beleg-Detektiv: Belege und Bestandsbuchungen](https://tfeulner23.github.io/BwR---Lernspiele/)
- [Abschluss-Check: Erfolgskonten, GuV und SBK](https://tfeulner23.github.io/BwR---Lernspiele/abschluss-check/) – Vorschau mit Speicherung im eigenen Browser. Zentrale Abgaben werden erst nach Einrichtung freigeschaltet.

Alle Beispiele verwenden fiktive Unternehmensdaten.
